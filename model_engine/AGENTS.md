# Agent Rules

## Communication
- Think in English.
- Answer the user in Korean.

## Code Comments
- Add short, focused code comments.
- Comments should explain *why* the code was written this way, not what it does.

## Git usage
- Commit proactively whenever a change is logically complete and worth checkpointing.

## Python usage
- Use `python3` instead of `python`.

## Subagent usage
- You can use subagents freely!
- Use model `GPT-5.4` at least, but reasoning efforts are up to you.
- English prompts are recommended when using subagents.
