짧게 결론

1. 원래 문제

서버엔진 개발자 작업분 위에 바로 내 커밋이 올라간 모양이어야 했는데, 중간에 불필요한 merge commit이 생겨 PR 히스토리가 복잡해졌습니다.

  • 문제 커밋: e4d5ee0
  • 커밋 메시지: Merge remote-tracking branch 'origin/model_engine' into model_engine
  • 결과: “풀 안 받고 작업한 뒤 나중에 합친 것처럼” 보임
2. 해결 방식

문제 있던 원격 상태는 백업 브랜치에 보존하고, model_engine 브랜치를 서버엔진 개발자 커밋 위에서 다시 만들었습니다.

  • 기준 커밋: 2a037b8
  • 내 커밋만 다시 적용: 5189eb5, 5410774
